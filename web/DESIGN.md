# Kakozane 前台设计规范 · Yohaku

唯一视觉参考：[Innei/Yohaku design-system](https://github.com/Innei/Yohaku/tree/main/design-system)，参考版本 `3631ac1561c977d4e96acc369577c5d7568679f6`。以 `src/tokens.css`、`CHEATSHEET.md` 和 showcase 当前主题为准（上游 README 的强调色说明落后于 token）。不再沿用 Apple 视觉规范。

## 统一规则

- 书写优先：暖纸色背景、衬线标题、三层中性色，一种克制的强调色。界面退居内容之后。
- `app/styles/yohaku-tokens.css` 是上游 MIT token 的普通 CSS 适配；本项目不用 Tailwind，无需为导入 token 引入整个框架。保留来源与许可于根目录 `THIRD_PARTY_NOTICES.md`。
- 浅色纸面 `#faf9f5`、正文 n-9 `#24231f`；深色纸面 `#1a1814`，中性色反转。强调色使用当前契约的梅色 `#c56473`，仅用于焦点、正文链接及少量状态标记。
- 三类字体：sans 用于界面与正文，serif 用于标题、引言及日期注释，mono 用于代码；均含中文回退。字体按本地可用性回退，不依赖第三方字体服务。
- 基础字号 14px，说明 12–13px，阅读正文 15px，栏目标题 20px，页面标题 28px，首页展示标题 36px。用户主动调整的阅读字号仍保留。
- 文字字号通过 `--text-*` 角色变量维护；标题与中文强调字重不超过 500。n-5 仅作边线，不用作正文。
- 表单默认 6px 圆角、卡片 8px、弹窗 12px；不使用大胶囊按钮或重阴影。深度通过细边线和 whisper shadow 表现。
- 登录注册在原生 dialog 内切换。桌面宽 380px，输入框高 36px，提交按钮高 34px；移动端输入文字保留 16px 以避免 iOS 自动缩放。Esc、遮罩、关闭按钮均可关闭，并恢复焦点。
- 搜索、评论、账号设置使用同一组紧凑控件；普通按钮采用中性色，强调色不铺满大块背景。
- 动效使用 `cubic-bezier(.22,1,.36,1)`，内容在进入视口时轻显现；同一会话重复访问不重复播放入场动画。遵守系统减少动态效果，禁用 JS 时正文仍可读。

## 页面布局

- 首页：居中个人介绍、真实统计、近期写作、活动及年月记录，留白服务于阅读。
- 文章：主列表与轻量搜索侧栏；移动端单栏；排序、摘要/紧凑视图和分页保持可用。
- 手记：年份与日期旁注、信纸布局；思考：短内容与作者时间；不强行混成相同卡片。
- 时间线：年份和月份层级，保留类型筛选及三档密度。话题、分类、页面索引沿用细边线文字列表。
- 正文：窄阅读列、宽屏侧边目录、代码和公式，手机单栏。图片放大、阅读进度、字号字体选择和沉浸模式保留。
- 友链/项目：桌面两列、手机单列；一言采用引文排版；订阅只列真实 RSS。
- 页头：紧凑导航、搜索、主题切换和登录；手机菜单提供全部入口。
- 页脚：站点署名、少量链接；在线人数固定在文档流中的页脚右侧，不悬浮。人数仍为近 75 秒活跃浏览器的近似值。
- 空状态、404、账号设置、登录注册、搜索弹窗与内容页共用主题与文字规则。

## 验证

```bash
cd web
corepack pnpm typecheck
corepack pnpm build
node --test "app/**/*.test.mjs"
```

浏览器检查桌面/手机、浅色/深色、登录注册切换与焦点、目录/搜索/分页，以及无横向溢出。CSS 和 SSR 构建通过不能替代浏览器检查。
