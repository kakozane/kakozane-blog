# Kakozane 前台设计规范

参考 [VoltAgent 的 Apple DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/apple/DESIGN.md) 的色彩与交互原则，内容组织延续文章、手记和混合时间线各自的入口；当前排版参考 [Yohaku 设计系统](https://github.com/Innei/Yohaku/tree/main/design-system) 及 [Innei 站点](https://innei.in/)。以实际页面为准，借鉴其分栏、内容密度、分类型排版与轻量目录，保留本项目的系统蓝。布局与组件由本项目实现。

## 气质

阅读优先。近白纸面与低对比灰阶，清晰的无衬线标题，灰色说明，蓝色集中用于正文链接、主要操作与焦点。让标题、摘要和正文构成视觉重点。支持与系统同步的深色主题。避免大号英文眉题、渐变、光晕、悬浮卡片、装饰图形和重复的行动口号。

## 色彩与字体

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 纸白 | `#fdfdfb` | 文章与页面主体 |
| 浅灰 | `#f4f4f1` | 控件、代码与引用背景 |
| 正文 | `#1d1d1f` | 标题与正文 |
| 次要文字 | `#6e6e73` | 日期、摘要、说明 |
| 发丝线 | `#e8e8ed` | 列表和区块分隔 |
| 操作蓝 | `#0066cc` | 链接、按钮与选中状态 |

字体优先系统栈：`-apple-system, BlinkMacSystemFont, SF Pro Text, PingFang SC, system-ui`。界面与标题使用系统无衬线字体，标题字重 500；衬线栈（Iowan Old Style、Songti SC、STSong、Georgia）用于引文及读者主动选择的阅读字体。首页与页面主标题 28–36px，栏目标题 22–24px；正文 17–18px，行高 1.85。统一通过 CSS 字体变量维护，不加载第三方字体。深色纸面使用 `#1c1c1e`，次级表面使用 `#262628`。

## 组件规则

- 桌面顶部使用居中的轻边框分段导航，以浅底色标识当前栏目；1020px 以下用底部浮动菜单收起全部栏目链接，保留顶部登录和主题切换。站名过长时只截断页头显示，不挤掉操作按钮。
- 页脚只保留关于、订阅、RSS 与已配置的 GitHub 链接；其余栏目由页头菜单进入，避免在手机上重复铺满导航。
- 站长可在后台为“更多”和手机菜单添加少量自定义链接，用于公开页面或 HTTPS 站点；内链保持同站导航，外链明确标记并在新标签打开。
- 首页使用 760px 窄栏，按小头像、个人问候、标语、介绍和真实统计的顺序展开；无头像时不显示占位图。最近写作采用编号文字目录，保留日期和分类，摘要及封面可在文章页查看。首页搜索与分类入口集中到页头和文章页，减少首屏控件。首屏轻量动画遵从系统“减少动态效果”设置。
- 首页标语在窄屏优先按标点换行，保持“记录”“思考”“分享”等短语完整。
- 站长近况由后台填写表情与简短文字，放在首页引言下方；不使用装饰卡片，过期或未填写时不占空间。后台保存后，已打开的页面通过站点事件刷新近况。
- 最近动态放在文章目录之后，桌面两列、小屏一列，混排公开发布、已审核评论与匿名点赞；下方按月展示过去一年的公开内容数量，有内容的月份可直达筛选结果，仅有一个活跃月份时显示简短统计。其他栏目以轻量文字入口呈现，不填充假数据。
- 首页引言下方用一行真实数字显示已发布的文章、手记、思考数量和首次发布时间；没有公开内容时隐藏整行。
- 首页允许站长把精选文章置顶，用蓝色小字标注；归档、时间线和订阅源仍按发布时间排列。
- 独立文章页保留封面与摘要列表，可只搜索文章；按时间排列的简洁归档保留独立入口。
- 文章页可按最新、最早或最近更新排序，并切换摘要和紧凑列表；搜索、翻页保留选择，URL 可直接分享。首页仍按发布时间显示摘要列表。
- 手记是有标题的随笔，思考是正文优先的短想法；时间线合并三类内容，并按年份和类型筛选。
- 手记可以用分类组织为专栏；专栏页只列出含已发布手记的分类，详情按发布时间列出手记。
- 站长可标记精选手记；手记页与时间线提供筛选入口，蓝色小字提示精选状态，仍按发布时间排列。
- 分类与标签各有独立的内容页，沿用时间线的简洁列表，显示对应的文章、手记和思考。
- 话题索引只列出有公开内容的分类与标签，以文字链接代替标签云和装饰卡片。
- 一言独立展示摘录及其作者、出处。桌面用两栏瀑布式排列，窄屏自动单栏；卡片只用系统蓝强调边线。
- 订阅页用细分隔线列出真实可用的 RSS 源，提供打开和复制地址操作，不展示尚未接入的邮件订阅表单。
- 友情链接按友站和收藏分组；只显示真实提供的头像，列表沿用细分隔线。
- 项目页展示可在后台维护的项目名称、简介与外部地址，沿用友情链接的列表排版。
- 自定义页面由后台发布，前台以文章正文的排版阅读，沿用章节目录、图片大图和 Markdown 扩展；“关于”页也使用相同的正文渲染。页面索引只展示真实已发布内容。
- 无效链接与暂时故障使用同一套页头、页脚和正文留白；404 提供首页与搜索入口，故障页提供重新加载，开发诊断信息默认收起。
- 公开发布新内容时，在当前打开的前台页面给出一条可关闭的轻提示。
- 列表图片只展示文章真实封面；没有封面时保持纯文字排版。
- 文章列表桌面采用主列表与 224px 搜索/话题侧栏，760px 以下搜索回到列表上方。排序与显示方式采用小号文字和选中下划线，避免多层胶囊控件；登录等提交按钮保留现有样式。
- 页头搜索按钮或 ⌘K / Ctrl+K 打开原生对话框中的快捷搜索，结果按发布时间混排；完整搜索仍有独立页面。面板使用系统背景、细边线和低对比阴影。
- 搜索结果同时包含已发布的文章、手记、思考和自定义页面，并清楚标出内容类型。
- 文章正文容器宽度 760px（含两侧 24px 内边距），链接使用操作蓝，代码和引用保持低对比背景。
- Markdown 提示块支持 `NOTE`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION`；采用低对比灰底与细色边线，浅色和深色主题均保持文字可读。
- Markdown 的 `mermaid` 代码块在浏览器中按需渲染，沿用系统蓝和主题色；加载或解析失败时保留源码，图表不应撑大正文列。
- Markdown 脚注使用中文标题和细分隔线，引用与返回链接沿用操作蓝；任务清单复用原生只读复选框，不把编辑控件放进公开文章。
- 长文章展示二三级标题目录与阅读进度；代码和公式在服务端完成渲染，代码块标出语言并可复制。宽屏在正文右侧提供轻量点赞、评论、分享和订阅入口，窄屏保留正文末尾操作区。
- 文章与手记的标题区用轻量文字显示字数、预计阅读时间及有意义的更新日期，不另加信息卡片。
- 文章超过半年未更新时，在正文前用低对比提示读者核对最新资料；手记与思考不显示此提示。
- 小屏用固定目录入口快速跳到章节；标题旁提供低干扰的章节固定链接，键盘聚焦时也清晰可见。
- 阅读字体可在系统默认字形和系统衬线字形间切换，并记住当前设备的选择；不用第三方字体服务。
- 正文可在标准、较大、最大三级字号间切换，选择只保存在当前浏览器；代码块等功能性文字保持各自字号。
- 长文章和手记提供低干扰的“继续上次阅读”文字入口，位置只留在当前浏览器，不自动跳转；读完或正文更新后失效。
- 文章和手记可手动进入沉浸阅读，暂时收起导航、目录及评论等周边内容；固定的退出按钮和 Esc 均可恢复页面。
- 正文中独占一行的图片可打开大图；图片说明使用 Markdown 的替代文本，带链接的图片仍保持链接行为。
- 正文末尾的继续阅读优先推荐同标签、同分类的内容，再以同类型的新内容补齐。
- 正文末尾另有按发布时间排列的上一篇与下一篇，只连接已发布的同栏目内容；标题完整换行显示。
- 后台文章、手记与自定义页面编辑器可把当前未保存内容送入独立前台预览页；预览只显示排版，不提供公开内容的点赞与评论操作。
- 评论回复显示被回复者名称，并在选择回复后把输入焦点移到评论框。
- 登录读者可在内容页看见自己的待审或未通过评论，提交后 10 分钟内可修改；修改时沿用评论框，保存后恢复待审状态。
- 从文章点赞或评论入口登录、注册后回到原内容；评论入口回到评论区，站外返回地址一律忽略。
- 读者账号页按时间列出本人喜欢过且仍公开的内容，使用简洁列表和分页，不显示其他人的点赞身份。
- 每条评论可打开固定链接；地址包含评论 ID 和锚点，打开时按当前排序计算所在分页并用浅灰底标出目标评论。后台可置顶已通过审核的一级评论，置顶标记沿用操作蓝。
- 评论正文与输入预览使用相同的轻量 Markdown 样式；外链使用操作蓝，图片只显示替代文字，不在评论区加载远程资源。
- 登录用户选中正文文字时，可把片段作为 Markdown 引用带入评论框；保留已有草稿，引用长度受评论上限约束。
- 按钮与输入框保留清楚的键盘焦点；触摸目标尽量达到 44px。

## 响应式

首页介绍、文章目录和页脚保持统一窄栏。680px 以下动态改为单列，头像缩小，年度发布图表分成两行；480px 以下其他栏目保留紧凑双列、文章页封面置于文字上方、时间线日期独占一行。新增页面沿用相同颜色、字体和间距。

### 视觉与动效观察

- 不能用“所有标题改宋体”概括这个站：文章界面主要无衬线，手记正文和引文才突出衬线，项目有等宽字体风格。
- 留白按页面角色分配：首页开场宽松，文章列表紧凑，手记有信纸内边距。栏目标题、工具条和内容边缘必须对齐。
- 参考站有强调色细节、低对比边框、弱阴影；它不是所有页面都没有卡片。Kakozane 保留系统蓝，先统一结构和层级。
- 实测样式中常见颜色过渡约 150ms，置顶卡悬停约 250ms，轻微上移 1px；部分侧边区域布局过渡约 520ms。不能据此推断所有 JS 动画时长。
- 首页/长列表存在进入视口后显现的内容；初始整页截图会留下空白，不能把空白误判为没有内容。还观察到数字翻动、关键词光标/变化及背景飘落元素。
- 搜索是覆盖当前页的面板，背景降对比。已实际打开搜索、标签云、邮件订阅弹窗，并切换深色主题；未发送表单或登录。
- 手机端侧栏收起为搜索/全部标签入口，底部有悬浮导航条；这与当前 Kakozane 的顶部菜单方案不同，尚未迁移。
- 本轮只增加文章区域 240ms 的轻入场与链接颜色过渡，复用现有 CSS；尊重 `prefers-reduced-motion`。复杂背景效果、全站弹簧动效与音频朗读尚未实现。

### 后续实施顺序

1. 已处理文章列表错位、隐藏标签、工具条密度、移动端和标题字体。
2. 首页按实际模块顺序重排；文章详情按标题/正文/侧边工具重新分配空间。
3. 手记独立信纸布局，思考动态流，时间线密度，友链/项目分别处理。
4. 基础页面稳定后，再补全滚动入场、面板过渡和可关闭的背景效果；不为了效果让 SSR 内容默认不可见。
5. 翻译、朗读、邮件订阅、媒体卡及留言板按实际需求做完整前后端能力，避免空壳入口。


## 本轮改造落地（2026-10-02）

上方逐页复核保留为研究记录；本节描述当前实现，替代其中已完成项目的“尚未实现”状态。

- 新的 `editorial.css` 负责页面版式，`app.css` 保留主题变量、基础控件和 Markdown。首页改居中头像/姓名/介绍，下方保留真实文章、活动、发布记录；没有头像时显示站名首字。
- 手记列表增加年份、日期栏、最新信纸大卡与普通卡，详情通过内容类型显示独立信纸视觉。数据不足时呈现真实空状态，不生成内容填充页面。
- 思考采用作者/时间开头的动态卡；友链双列头像卡，缺头像时显示首字；项目双栏文字目录；一言弱边框与衬线引文。
- 时间线增加月份标题及舒展/紧凑/速览三个真实密度切换，保留原有年份、类型、精选和分页功能。
- 宽屏正文目录放在右侧，快捷操作位于其下；小屏目录与底部菜单、在线徽标错开。
- 首页挥手、卡片轻悬停、内容进入视口的动画均遵循减少动态效果。JS 不运行时仍可直接看见正文；页脚背景动效可关闭并记住选择，默认关闭。
- 在线徽标统计近 75 秒仍保持 SSE 心跳的匿名浏览器，每 25 秒刷新。它不代表登录用户数，不展示身份。断线隐藏，同一站点的浏览器标签页通过共享随机标识去重；细节见 README。
- 本轮改造覆盖现有功能的视觉与浏览体验；翻译、AI 朗读、邮件订阅和独立留言板仍属于未接入的业务能力，没有添加空壳入口。
